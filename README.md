# Banvas

A fast, clean Canvas LMS client for iPhone. 更快、更清楚的 Canvas 客户端。

> Banvas is currently in internal testing and isn't on the App Store yet.

[Support](https://boyuchengz.github.io/banvas/) · [Privacy policy](https://boyuchengz.github.io/banvas/privacy.html)

## Privacy

Banvas talks directly to your school's Canvas server. Your Canvas URL and access token stay in the iOS Keychain on your device, nothing passes through a server of ours, and the app contains no analytics, advertising or third-party SDKs.

## About this repository

The app's source is private. This repository hosts the support page and privacy policy served by GitHub Pages. Bug reports and feedback go in [issues](https://github.com/boyuchengz/banvas/issues).
